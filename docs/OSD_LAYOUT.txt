All elements are configurable via OSDConfig:

  enabled: bool = True              # Master on/off switch
  show_compass: bool = True         # Compass widget visibility
  compass_radius: int = 45          # Compass size in pixels
  show_sbus_channels: bool = False  # SBUS debug display
  font_scale: float = 0.6           # Text size multiplier
  font_thickness: int = 1           # Text stroke thickness
  background_alpha: float = 0.5     # Text box transparency

Example config.json:
  {
    "osd": {
      "enabled": true,
      "show_compass": true,
      "compass_radius": 45,
      "show_sbus_channels": false,
      "font_scale": 0.7,
      "background_alpha": 0.6
    }
  }

Rendering overhead: <1ms per frame @ 640×480 on Raspberry Pi 3B+
  - OpenCV drawing primitives are highly optimized C++ code
  - Text rendering uses pre-rasterized fonts
  - Semi-transparent overlays use cv2.addWeighted (SIMD-accelerated)
  - All operations modify the frame buffer in-place (no copies)

The OSD is designed for real-time operation at 30fps without impacting
camera frame rate or gimbal control loop timing (50 Hz).

from cymbal.osd.overlay_controller import OSDOverlay

osd = OSDOverlay(config.osd)
osd.initialize()

# Update telemetry from sensors (typically in control loop)
osd.update_telemetry(
    lat=33.44827,
    lon=-112.07400,
    alt_agl=152.3,
    groundspeed_ms=28.5,
    address="123 Main St, Phoenix AZ",
    fix_quality=2,      # 2 = DGPS
    satellites=12,
    sbus_channels=[992, 992, 1024, ...],  # optional
    track_degrees=45.0,
    camera_yaw_deg=15.0,
)

# In camera frame callback
def on_frame(frame):
    osd.render_frame(frame)  # Annotates frame in-place
    # ... encode/stream/save frame ...

osd.close()

Position: Horizontally centered, 2% from top edge
Default size: 7% of frame height, 25% of frame width
Field of view: ±15° from camera heading (30° total span)

                  ┃   │     │     │     ▼     │     │     │   ┃

                  ┃             SE  S  SW     135°            ┃
                  ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

Components:
  - Tick marks: 1° intervals (short), 5° intervals (long with labels)
  - Degree labels: Every 5° (005, 010, 015, 020, ... 355, 000)
  - Cardinal directions: N/E/S/W shown BELOW degree labels at 0°/90°/180°/270°
  - Center chevron: Downward-pointing triangle at center (current heading)
  - Heading box: Framed numeric value below tape showing current heading
  - Semi-transparent background (black @ 50%) with white border

Camera Heading Calculation:
  - Absolute camera heading = GPS ground track + camera yaw offset
  - Example: Track=100°, Camera Yaw=+35° → Heading=135°
  - Automatically handles wraparound at 0°/360° boundary
  - Suppressed when either GPS track or camera yaw is unavailable (NaN)

Wraparound Examples:
  - Heading=5°:   Tape shows 350°-355°-000°-005°-010°-015°-020°
  - Heading=135°: Tape shows 120°-125°-130°-135°-140°-145°-150°
  - Heading=355°: Tape shows 340°-345°-350°-355°-000°-005°-010°

Configuration Options (in osd config section):
  - show_heading_tape: bool = True
  - heading_tape_height_pct: float = 0.07 (7% of frame height)
  - heading_tape_width_pct: float = 0.25 (25% of frame width)
  - heading_tape_fov_deg: float = 30.0 (±15° field of view)
