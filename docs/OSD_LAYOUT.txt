  - Text: White (255,255,255)
  - Font: cv2.FONT_HERSHEY_SIMPLEX
  - Font scale: 0.6
  - Thickness: 1
  - Line spacing: 28 pixels × font_scale

Compass Widget:
  - Background disc: Black (0,0,0) @ 55% transparency
  - Ring (with GPS fix): Light gray (180,180,180)
  - Ring (no GPS fix): Dark gray (80,80,80)
  - Track arrow: White (255,255,255)
  - Camera arrow: Yellow/Cyan (0,255,255) in BGR
  - Labels: Matching arrow colors

Line 1:  Timestamp (UTC) - HH:MM:SS format
Line 2:  Address - Reverse geocoded street address or "Unknown address"
Line 3:  GPS Position - Lat/Lon in decimal degrees (5 decimal places)
         Shows "GPS: No fix" when no position available
Line 4:  Altitude AGL - Above Ground Level in meters
         Shows "Alt AGL: --" when terrain data unavailable
Line 5:  Ground Speed - In meters per second
         Shows "GndSpd: --" when no GPS velocity data
Line 6:  Fix Quality - "No fix", "GPS", or "DGPS"
         Satellites - Number of satellites in view
Line 7+: [Optional] SBUS channel values (when show_sbus_channels=True)
         Two rows: channels 1-8 and 9-16

All elements are configurable via OSDConfig:

  enabled: bool = True              # Master on/off switch
  show_compass: bool = True         # Compass widget visibility
  compass_radius: int = 45          # Compass size in pixels
  show_sbus_channels: bool = False  # SBUS debug display
  font_scale: float = 0.6           # Text size multiplier
  font_thickness: int = 1           # Text stroke thickness
  background_alpha: float = 0.5     # Text box transparency

Example config.json:
  {
    "osd": {
      "enabled": true,
      "show_compass": true,
      "compass_radius": 45,
      "show_sbus_channels": false,
      "font_scale": 0.7,
      "background_alpha": 0.6
    }
  }

┃ PERFORMANCE                                                           ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

Rendering overhead: <1ms per frame @ 640×480 on Raspberry Pi 3B+
  - OpenCV drawing primitives are highly optimized C++ code
  - Text rendering uses pre-rasterized fonts
  - Semi-transparent overlays use cv2.addWeighted (SIMD-accelerated)
  - All operations modify the frame buffer in-place (no copies)

The OSD is designed for real-time operation at 30fps without impacting
camera frame rate or gimbal control loop timing (50 Hz).

┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛

from cymbal.osd.overlay_controller import OSDOverlay

osd = OSDOverlay(config.osd)
osd.initialize()

# Update telemetry from sensors (typically in control loop)
osd.update_telemetry(
    lat=33.44827,
    lon=-112.07400,
    alt_agl=152.3,
    groundspeed_ms=28.5,
    address="123 Main St, Phoenix AZ",
    fix_quality=2,      # 2 = DGPS
    satellites=12,
    sbus_channels=[992, 992, 1024, ...],  # optional
    track_degrees=45.0,
    camera_yaw_deg=15.0,
)

# In camera frame callback
def on_frame(frame):
    osd.render_frame(frame)  # Annotates frame in-place
    # ... encode/stream/save frame ...

osd.close()
